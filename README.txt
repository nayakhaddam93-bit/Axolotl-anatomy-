Axolotl Anatomy - حزمة جاهزة لمواقع تحويل HTML إلى تطبيق

- الملف الرئيسي: index.html (ملف واحد كامل، فيه كل الأكواد والخط والصور، لا يحتاج إنترنت).
- إذا الموقع بيطلب ملف واحد: ارفعي index.html فقط.
- إذا بيطلب مجلد/ZIP: ارفعي الـ ZIP كما هو (index.html بالجذر).
- إذا بيطلب لصق الكود: افتحي index.html بمحرّر نصوص وانسخي كل المحتوى (من أول <!DOCTYPE إلى آخر </html>).
- الأيقونة: icons/icon-512.png (للتطبيق) و icons/icon-maskable-512.png (أندرويد).
- الاسم المقترح للتطبيق: Axolotl Anatomy  |  اللغة: العربية RTL  |  الاتجاه: عمودي.
- صلاحيات لا يحتاجها التطبيق (اطفئيها إن سألك الموقع): الكاميرا، الموقع، التخزين الخارجي. يحتاج إنترنت فقط لروابط القناة والإنستغرام.
